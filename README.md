# Daily Growth

A long-running software-engineering knowledge base documenting my journey across backend, frontend, data engineering, architecture, automation, testing, distributed systems and AI.

The repository is being reorganised into a canonical engineering notebook so that durable examples, notes and patterns from older standalone repositories can live in one coherent place.

## Target structure

```text
architecture/        # DDD, SOLID, design patterns, clean architecture
computer-science/    # algorithms and core CS exercises
languages/           # Python, Scala, Java, TypeScript, Rust, Groovy, Swift
Databases/           # database-specific examples and notes
frontend/            # reusable frontend patterns and experiments
devops/              # CI/CD, GitHub Actions and operational patterns
ai/                  # AI, MCP and LLM experiments
guides/              # concise engineering guides and runbooks
projects/             # self-contained learning projects that still add value
```

Existing material will be moved into this structure incrementally. Older standalone learning repositories will only be retired after their useful authored content has been migrated and verified.

## Background

I studied Human Nutrition before moving into technology and have since worked across banking, testing, automation, backend and frontend development, data engineering, full-stack development and AI-related systems. This repository is the durable record of that continuing engineering growth.
