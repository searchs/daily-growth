# GitHub Actions reference examples

These files are reference material and intentionally live outside `.github/workflows/`, so they do not execute in this repository.

## Sources

- `rust-ci.yml` was consolidated from the historical `searchs/rust-systems-programming` fork, where the unique authored value was the GitHub Actions Rust pipeline.
- `prune-workflow-runs.yml` was consolidated from `searchs/SaaS-Foundations`, whose only unique change over upstream was the workflow-run pruning automation.

Review action versions, permissions and retention settings before copying an example into an active repository.
