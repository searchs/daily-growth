# Groovy Workbook

Historical Groovy learning material migrated from `searchs/groovybox` during repository consolidation.

The workbook captures exploratory language exercises around ranges, collections, closures, XML/JSON parsing, sorting and reduction patterns. It is preserved as learning history rather than presented as production-ready code; some examples use old external endpoints and may need modernisation before execution.

Source repository can be retired after this migration is reviewed and verified.
