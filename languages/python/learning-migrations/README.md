# Python learning migrations

This section consolidates durable lessons from older standalone learning repositories while avoiding wholesale copies of course assets, generated artefacts, datasets and obsolete dependencies.

Sources currently represented here:
- `python-mastery-ztm`
- `hotels_py_intro`
- `fraud-detection-apps`
- `rhema`

The goal is to keep reusable concepts and authored practice, not preserve course completeness.
