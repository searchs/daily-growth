# TypeScript Fundamentals

Curated TypeScript learning examples migrated from the former `typescripts/fetchjson` sandbox.

The original folder mixed language exercises with an obsolete npm dependency surface (`axios`, a typo/security placeholder package, and `nodemon`). The durable examples are kept here without a local package manifest or lockfile.

## Examples

- `variables.ts` — variables, annotations and basic types
- `arrays.ts` — array typing
- `tuples.ts` — tuple examples
- `interfaces.ts` — interfaces
- `objects.ts` — object typing
- `classes.ts` — class syntax and modelling
- `fetch-json.ts` — typed JSON retrieval using the platform `fetch` API

These are learning snippets, not a standalone application. Modern TypeScript runtimes provide `fetch`, so the JSON example no longer needs Axios or a repository-local dependency graph.

## Provenance

Authored examples preserved from the repository's earlier `typescripts/fetchjson` learning area during the canonical knowledge-base cleanup.
