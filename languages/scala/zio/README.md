# Scala / ZIO Learning

Curated material migrated from `searchs/ZioBegins` during repository consolidation.

The original repository was created while learning ZIO and functional programming in Scala, using the article *Introduction to Programming with ZIO Functional Effects* as a reference. The surviving authored example focuses mainly on the functional-programming foundations required before deeper ZIO work: total functions, deterministic state passing, mutation and side effects.

The old repository also contained a generic hello-world entry point and a large illustrative image; those were not migrated because they add little durable engineering value.
