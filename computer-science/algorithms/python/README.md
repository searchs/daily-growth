# Python Algorithms

Curated algorithm exercises migrated from `searchs/algorithms` during repository consolidation.

The original repository contained small standalone scripts for linear/binary search, Fibonacci, recursion exercises, bubble/insertion/selection/merge/quick sort and array splitting. They have been consolidated here into clearer topic modules with import-safe examples and simple assertions.

This migration preserves the authored learning value while avoiding a one-repository-per-exercise structure.
